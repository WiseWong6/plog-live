# 盲测选样B组

10张真实摄影日记原照片，7位作者。共约3.0MB；5张横图、4张竖图，含1张方图，包含黑白、彩色、暗背景、明亮天空、拥挤近景和人物生活照。

按预设五类各取两张，在搜索到的真实摄影日记中先找到可用正文照片即锁定。选样者只读来源网页、检查原照片类别及能否解码，未查看项目动效、未运行技能、未调参数。不是随机人口抽样，也不代表全体PLOG，属于公开摄影日记的便利样本。没有使用图库代理样本。

## 原照片与界面区分

所有照片来自网页正文图片地址，不含网站界面，不进行裁图、生成或任何图片修改。火山湖候选第一张带作者叠加的大段文字，因此在任何动效运行前排除，按正文顺序改用下一张，原候选地址和原因保留在清单。马缨丹方图保留原作者的小型署名水印。

## 来源与使用边界

来源页面、原图地址、作者、类别、文件散列和尺寸记录在manifest.json。只用于本次本地盲测，不发布他人图片。除Feline Café页面显示的CC BY-NC-ND 4.0标志外，其他来源未发现明确开放授权，不应当作自由素材库。猫照片的本地衍生测试同样不对外发布。

未留下网页缓存、提取程序或其他临时文件。
