# 首版开发检查

日期：2026-09-27。范围：纸片雨帘、离线预览、固定时刻渲染和苹果实况照片封装。

| 检查 | 结果 |
| --- | --- |
| 正式样片导出 | 1440×1920、3 秒、30 帧/秒，共 90 帧，无音轨 |
| 动作稳定性 | 首尾完全一致；跳转后回到同一时刻画面一致；独立时间采样确认存在运动 |
| 原图保护 | 原图副本的 SHA-256 与输入一致；默认画布保持原比例 |
| 文件保护 | 已存在的场景或导出目录拒绝覆盖，内部用户文件保留 |
| 输入错误 | 缺失照片、缺失场景、重复参数、未实现效果均拒绝继续 |
| 路径兼容 | 场景目录包含中文与空格可用 |
| 首帧封面 | 修正封面时间为零时的误判；独立的 30 帧小样成功导出 |
| 浏览器初始化失败 | 用失败程序代替浏览器，异常被捕获，临时浏览器目录清除 |
| 语法与模板同步 | 10 份 JavaScript 与 Shell 检查通过；交付页面与模板的核心文件一致 |
| 技能入口 | 本机软链接指向唯一技能源目录；配置要求明确手动调用 |
| 实况资源配对 | JPEG 与 MOV 标识一致，关键照片标记为 1.5 秒，精确对齐视频帧 |
| 苹果系统解码 | 返回完整、非静态占位的实况照片对象 |
| 原生封装边界 | 错误参数、缺失文件、越界/非有限时间、非法名称、未配对输入、已有文件保护检查通过 |
| 封装编码保留 | 静音及带音频小样均成功，原视频和音频编码数据保持一致 |
| 原生应用入口 | 应用包只读取本次临时副本的验证路径通过，未调用相册权限或写入 |

正式渲染的原始记录见 [渲染报告](paper-rain/render-report.json)，正式苹果配对的原始记录见 [苹果资源报告](paper-rain/live-photo/plog-paper-rain.validation.json)。

工具的当前实现依赖本机 Node.js、Chrome、FFmpeg；创建场景需 macOS 自带的元信息工具，原生封装需 macOS 26+ 与可用的 Apple 开发工具 26+。未安装第三方依赖，未修改系统开发工具选择。

没有代替用户进行浏览器操作、截图或观感验收。没有导入照片库；相册权限与写入、iPhone 长按、目标发布平台仍待实际验收。首版只实现纸片雨帘，其余七类效果为设计配方。

检查产生的临时场景、小视频与失败样本均已清理；约 247 MB 编译模块缓存已删除，只保留约 280 KB 可运行应用包。没有逐帧图片序列。正式交付物和生成底图保留至验收。
