# 成片检查

- **原件与构图：** 核对原件校验值、显示方向、比例与四边内容；检查主体轮廓与已有纹理。
- **英文小字：** 在实际成片上核对英文与任务文案一致、贴合本图含义（用户指定文案除外）；文字紧邻主体、完整易读，未遮挡主体轮廓、食物纹理、手、人脸和既有文字。
- **动效：** 检查路径与照片物件的关系、完整循环、暂停和重播的一致性；按[动线规范](motion-layout.md)核对杯口起点、全幅覆盖和局部遮挡。
- **声音与原动态：** 照片版无音轨；原动态版核对帧时刻、时长、封面时刻及原声音轨，静音任务确认音轨已移除。
- **分布与方向：** 飘落核对首帧、封面和中途不成等距横排、斜排或队列；鸟蝶核对当前照片的方向依据、完整曲线与身体朝向，同批照片不无依据地套用同方向。程序检查不替代观感确认。
- **实况文件：** 查看 `live-validation.json` 中的配对信息与苹果完整解码结果。
- **对比页：** 核对资源可离线加载，左右两侧同步切换、完整显示，暂停与后台行为符合主技能的交付规范。

交付前检查 `receipt.json` 和失败信息。文件校验、相册导入、iPhone 播放与小红书表现分别以实际结果为准；只有执行过的检查才报告通过。
