# 超现实效果配方

一张照片默认只发生一个主要小事件。每个效果都必须说明支点、避让、遮挡、材质、运动、闭环和不适用条件；没有这些关系的随机贴纸不作为完成方案。

用户补充的手工纸云参考是首个正式实现方向：米灰纸面、深蓝不规则云、细线串起的长水滴，灰蓝与白为主，少量砖红点缀。参考中的播放按钮、字幕与英文字全部排除。背景米灰纸不要求覆盖真实照片。

这些参考均为截图。下面的摆动速度、出现时机与循环方式属于本技能设计，不是对原参考视频运动的事实描述。

## 纸云串雨：当前可运行效果

**事件：** 一朵手工纸云悬在照片的空隙里，细线上的纸雨滴被微风轻轻吹动。

- **支点：** 云下缘是细线共同依附的位置。云的整体位置对应桌边、杯上方或窗前的一处留白，不能在重播时随机改位置。
- **避让：** 云、线与雨滴避开脸、手、食物关键细节和杯口。线长随留白调整，不为了铺满画面让水滴盖住主体。
- **遮挡：** 首版以留白中的悬挂物为主。只有当前模板确实提供且配置了遮挡时，才让元素从实物后面经过；否则不得把“进入杯中”“穿过窗框”当成已实现行为。
- **材质：** 云为深蓝剪纸形，边缘略不规则；雨滴细长，使用灰蓝、深蓝、白和少量砖红。细线保持纤细。避免亮塑料、霓虹发光、大面积透明玻璃感或自动添加表情。
- **运动：** 线的上端与云保持连接，下端摆幅稍大；水滴始终在线上，邻线稍有错落但属于同一阵风。它们不独立坠落、爆炸、弹跳或不断重新生成。云只做克制的漂动。
- **闭环：** 用可重复的周期变化描述姿态；一个周期结束时，云、线和雨滴回到与开头相同的位置与运动趋势。任何布局差异固定下来，保证拖回同一时间画面一致。
- **不适用：** 照片没有可用空隙、主体占满画面，或用户明确要求真实暴雨、镜头雨滴、写实水滴落入液体。此时先调整构图方案或说明需要另一效果，不能硬贴纸云。

推荐起点是 3 秒一轮；摆幅以完整看见照片主体为限。具体线数、雨滴数量和位置由照片决定，不把参考的一次布局固化成所有照片的模板。

当前配置的效果名称是 `paper-rain`。位置以画布左上角为起点，用 0 到 1 的比例表达；云宽度与摆幅相对于画布宽度，雨帘长度相对于画布高度。创建脚本当前按顶层覆盖配置，修改 `cloud` 或 `curtain` 时应提供该对象的完整字段。

```json
{
  "effect": "paper-rain",
  "cloud": { "x": 0.515, "y": 0.19, "width": 0.30, "color": "#284b82" },
  "curtain": { "length": 0.28, "strings": 12, "sway": 0.020 }
}
```

这是可调整的起点，不代表任意照片都适合这些位置。其他配置字段与允许范围以随包模板为准。

## 流星：设计配方，尚未实现

- **支点：** 杯缘、窗边、书页或暗色留白中的一条清晰路径。
- **避让：** 轨迹避开人脸、手势和食物主体，不在每个空白角落同时出现。
- **遮挡：** 需要穿到实物后方时，必须有对应遮挡范围；否则将完整路径安排在主体之外。
- **材质：** 可选纸片星星与细尾，或克制的局部微光；同一张图只用一套语言。
- **运动：** 一颗主流星经过支点，带出少量短暂回应。尾迹与星体连续，不像随机划线。
- **闭环：** 在无流星的安静状态连接首尾，或者采用完整闭合轨迹；不要在边界瞬间传送可见星体。
- **不适用：** 本就杂乱的强高光背景，或必须靠大面积光效才能看清的照片。

## 亮片山水：设计配方，尚未实现

- **支点：** 山脊、水纹、叶脉或木纹的真实走向；静物可选杯沿与碟缘。
- **避让：** 不覆盖人物皮肤与食物的可辨认纹理，不均匀撒满整幅画面。
- **遮挡：** 亮片附着于选定表面；被前景挡住的部分不应透出来。需要遮挡时先具备对应能力。
- **材质：** 银色或轻微镭射反光，少量偏色只在高光处出现，暗下时仍像薄片。
- **运动：** 少量亮片沿结构依次反光，像一个很轻的角度变化，不把整个山水或物体摇动。
- **闭环：** 闪亮的相位连续，首尾保留相同的亮片位置和整体亮度趋势。
- **不适用：** 缺少可依附结构，或只能用强闪烁、满屏星芒才能成立的素材。

## 泡泡：设计配方，尚未实现

- **支点：** 杯口、水面、浴缸或窗前一个明确的出现位置。
- **避让：** 泡泡稀疏经过留白，避免大泡泡长期盖住脸和食物。
- **遮挡：** 需要从杯后出现或绕过吸管时，应配置前后关系；不能一律画在最上层。
- **材质：** 大部分透明，轮廓只有局部反光；可在个别泡泡内放一颗小亮片星，不把所有泡泡做成彩色圆球。
- **运动：** 从支点缓慢升起，大小和横向偏移有轻微变化，不随机四处碰撞。
- **闭环：** 在边缘或不可见处完成出现与消失；结束时不留下突然跳回底部的可见泡泡。
- **不适用：** 没有水、饮料或合理幻想关联，或源图太亮而只能用粗黑圆框表达泡泡。

## 飞鸟：设计配方，尚未实现

- **支点：** 书页、落叶、窗边或照片中一条通向留白的边缘。
- **避让：** 鸟群数量克制，不在人物五官附近闪过，不把主物件遮成剪影。
- **遮挡：** 可经过窗框或书页背后，但只有具备相应遮挡时才采用；地面影子必须对应同一只鸟的位置。
- **材质：** 纸片或手绘剪影，尺度统一；不混入毫无关联的写实鸟类素材。
- **运动：** 从同一支点飞出，沿一个有方向的弧线离开；翅膀动作服务于短距离飞行。
- **闭环：** 鸟离开后留一小段安静时间，下一轮从支点重新出现；不能在画面中央无故消失。
- **不适用：** 留白过窄、飞行路径必须穿过人物主体，或主题缺少可以解释的出发点。

## 雪花：设计配方，尚未实现

- **支点：** 杯旁、书上、窗前的一小片局部空间。
- **避让：** 不给全图均匀盖雪，主要人物和物件细节保持清楚。
- **遮挡：** 雪花接触桌面、杯沿或书页时遵守物体边界；若没有接触能力，就只在留白中轻落。
- **材质：** 少量纸片雪或细小柔白雪点，根据摄影质感选择一种，不混用大雪花图标和写实雪粒。
- **运动：** 克制地侧落；接近暖光处可轻轻消隐，体现一个有范围的小气候。
- **闭环：** 不累积无法复原的厚雪；开始与结束的落点状态一致，消隐应平滑。
- **不适用：** 用户要求真实暴雪或积雪增长，或者只能通过改变照片天气来成立的场景。

## 月亮：设计配方，尚未实现

- **支点：** 杯口、窗框、桌沿或液面上方的一处小空间。
- **避让：** 月亮作为小物件存在，不抢走照片主体，也不遮住人脸。
- **遮挡：** 若沿杯缘运行，前后段要对应杯沿遮挡；倒影只有在确实存在可反射表面并实现相应变化时才加入。
- **材质：** 哑光纸月或轻微珍珠光，颜色与照片相容；不默认做成巨大天体或强光灯。
- **运动：** 小幅悬浮、轻转或缓慢绕行，借不合理尺度制造惊喜。
- **闭环：** 选择完整周期的漂浮或轨道，首尾位置、亮度与倒影一致。
- **不适用：** 需要大幅改天换地，或月亮必须遮挡主体才能清楚可见的照片。

## 拼图：设计配方，尚未实现

- **支点：** 照片边缘、白盘边沿或桌面中一个小而清楚的局部。
- **避让：** 不切割脸、手、食物主体或难以保持辨认的关键部位。
- **遮挡：** 拼片与缺口必须一一对应，先明确拼片移开后露出的合法底层；不得自动脑补不存在的背景。
- **材质：** 真实照片内容保留在拼片表面，轮廓和厚度表现克制，不能改成无关贴纸。
- **运动：** 一小块照片抬起、短距离轻转后归位；其余照片保持静止。
- **闭环：** 准确回到原像素位置和朝向，无重影、重复边缘或错位；照片完整状态作为首尾。
- **不适用：** 当前无法保证缺口对应和准确复原，或需要重建照片背景才能实现。任何位图裁切、修复及蒙版制作仍受内置图像工具限定，不能借配方绕过。

## 扩展为可运行效果的条件

完成设计配方不等于完成开发。新增效果必须有真实实现、可配置的支点与范围、确定的时间控制、首尾检查和可导出样例，再更新能力状态。若尚未验证相册或手机，只提升动效能力状态，不顺带声称端到端实况照片已通过。
