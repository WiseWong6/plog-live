# 按照片设计动线

参考图提供材质和意象，不提供新照片的坐标。每张图先观察杯口、盘沿、食物摆放方向、拍摄透视、光线和英文位置，再选择动作。

## 先写五句话，再摆坐标

布局 `motionPlan` 必填：`intent` 意图、`anchor` 对应的照片物件或线条、`direction` 从哪里经过哪里到哪里、`depth` 前后层次、`overlap` 哪些地方允许交叠、哪些局部需要保护。主体矩形只是描述主体，不可直接复制到保护区。

- 飘落：一般为全幅气氛，设置 `scope:"full-frame"`。路径横向覆盖至少六成照片，纵向贯穿画面。远层小而稀、前层略大；允许少量前层落过食物。不能把全部粒子藏在主体后面，不能压缩成边框。`depthOcclusion:"far-only"` 只让远层被真实物件遮住；没有精确轮廓就不制造粗糙剪影遮罩。
- 气泡：优先从饮品杯口或液面升起，沿杯身方向向上再轻微散开。记录 `attachment:"cup"` 和 `origins:[{cx,cy,rx,ry}]`，全部起点落在杯口内，配置 `cupOrigin:true`，出生先小而淡，再自然展开。不从无关桌面发射；杯口贴上边缘、没有上升空间就换合适的照片或效果。
- 纸鸟、蝴蝶：顺着桌沿、摆盘、手臂或饮品之间的视线飞过。先定弧线中段经过的位置，再把两端放到画外；可以从主体前方经过，不统一塞到上边。蝴蝶可使用 `control` 曲线转弯。保留小纸翼与轻盈尺度，勿因全幅移动变成大图标。
- 流星：顺画面斜线贯穿，纵向错开。保持较长尾迹、缓慢连续掠过，头部和整条尾迹离开画外才复位。只绕开小字所在的窄区域，不绕开全部食物。
- 纸雨：找到可接雨的饮品和杯口，再定上方云的位置。云与饮品形成一组完整关系，雨落入当前液面并在杯沿后消失。没有合适饮品和垂直空间时，不硬塞到固体甜点上。
- 星月碎光：使用银色素材、部分虹彩和清晰闪光。根据桌面与盘面重排，不能变形；不能把这类静置亮片的布局方式套到飞行和飘落。

## 局部保护和时间

### 飘落不能从一排开始

横向位置与起始时间分别设计。禁止 `phase = 序号 × duration / 数量`，也不能在排序后的横坐标上分配递增相位。先摆路径，再调用 `scatterFalling(config, sourceSha256)`：它按固定种子分层打散时间、打乱对应关系，检查首帧、封面及周期的 23%、57%、81% 位置；只返回新配置，不修改原配置。将返回值写入布局的 `config`，播放时不抽随机数。相同照片和配置会得到相同结果。

`validateMotionLayout` 对五种飘落检查等距相位及大部分可见元素共线；未通过就调整相位或路径，不靠整体延后视频开头掩盖。同样检查大小、旋转、前后层与疏密，不把一个规则网格简单旋转成斜线。程序采样仅拦明显队列，不代表自然观感已验收。

### 鸟蝶按构图选方向

`config.flightDirection` 使用 `left-to-right`（向右）、`right-to-left`（向左）、`top-to-bottom`（向下）、`bottom-to-top`（向上）；斜向可归入主方向。复杂回转用 `custom`，并在 `motionPlan.direction` 写清路径依据。配置示例分别展示向左纸鸟与向上蝴蝶，不代表新照片必须照搬。

屏幕飞行可调用 `redirectFlight(config, direction)`：按模板已记录的方向转动 `from/control/to`，不转动照片、文字保护区或造型。然后按当前照片调整弧线中段、各条路径弯曲程度和时间错位。不要只翻转鸟蝶图案却让坐标继续往原方向移动。身体沿真实路径切线朝向，翼动保留。

单图可以是一组协调的同向飞行，也可以有少量不同弧线；不强求对冲。多图制作要逐图依据桌沿、手臂和物件关系选择方向；全部同向时必须有构图或用户要求依据。旧贴附鸟路径的终点在物件后，不能直接旋转旧遮挡轮廓；需要重新标注，或改成画外进出的屏幕飞行。

`safeRects` 只写文字及必要小区域。全幅飘落、气泡和飞行可用 `captionProtection:"local-fade"`：只在元素接近文字时短暂淡出，离开即恢复，其余位置照常显示。流星优先直接选择避开文字的整条路线。不要用一大块主体矩形替代精确遮挡。

时长、速度和密度可调，程序支持 2–12 秒的三十帧周期；具体效果仍验证自身形状、路径与资源限制。纸雨与星月碎光使用各自模板的周期规则。数量随画幅与物件尺度决定，不以增多代替融合。所有运动为确定时间的函数；停下、回拖、重播不重新抽随机数。封面时间、相位及循环都必须与调整后的周期一致。

原动态的配置限制见[装饰布局](effects.md)。
