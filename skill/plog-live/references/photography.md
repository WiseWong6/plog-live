# 摄影底图：暗调日常静物

摄影依据是最初三张参考截图中间的照片：木椅上的咖啡与书、手持双盘甜点、圆木桌上的咖啡与落叶。后续人物造型、游戏、恐怖和拼贴参考不改变这套摄影基底。

## 已观察到的风格

| 维度 | 照片中的依据 | 制作时怎样落实 |
| --- | --- | --- |
| 日常题材 | 咖啡、甜点、书、落叶、木家具与局部手势 | 像记录一段休息时间，围绕少量真实物件构图 |
| 光照 | 木椅、圆桌有局部阳光和清晰投影；双盘甜点较柔和 | 沿用原照片已有光向，不强行给每张图添加硬光 |
| 明暗 | 大面积深灰、炭黑背景托出受光主体 | 保留暗部材料层次，不把所有阴影压成死黑 |
| 配色 | 琥珀木色、金黄食物、灰紫杯子和深灰背景 | 暖色集中在物体上，少量冷色平衡；不整张泛黄 |
| 材料 | 木纹、粗陶、焦糖表面与粗粝地面 | 保留材料细节，不磨成塑料，也不靠满屏颗粒冒充质感 |
| 视角 | 近距离略俯视，圆盘与杯子自然错落 | 优先让主体完整、关系清楚，不强制居中或对称 |
| 生活线索 | 手、衣袖和拿叶片的动作 | 可以露出局部人物，但不无端重绘身份、肤色或手势 |
| 留白 | 主体周围存在低干扰的暗面 | 为幻想元素找到具体空隙，避免压住食物或人的脸 |

不从截图推断相机型号、镜头、拍摄参数、胶片种类或实际曝光补偿。需要新底图时，用可见的结果描述光照和质感。

## 原照片优先

原照片能够使用时就保留原件。摄影风格是选择素材和安排装饰的依据，不是自动把用户照片改造成参考照片的许可。

场景创建脚本逐字节复制输入文件。未指定画布宽、高时，只读原图尺寸与方向，自动生成最长边不超过 1920 像素、尽量匹配原比例的偶数尺寸画布。推荐的 3:4 不覆盖这条规则；默认不加黑边，也不为了套模板裁掉主体。

用户明确配置画布宽、高时，可按指定取景填满画面，源照片文件仍保持原样。此时应说明边缘可能被裁出画面，并核对人脸、手和主要物体；不要把保留原文件误说成所有内容都显示完整。

如果需要输出另一份经过裁切、调色、抠图或修复的照片素材，只能使用宿主内置图像工具，并保留原版。场景中的布局和显示取景不等于授权重绘照片。

有方向信息的照片，要在预览与渲染中确认方向一致，不能因为文件尺寸与显示方向不同而把竖图误当横图。

## 主题生成底图

用户没有提供原片、希望从主题创作时，可以生成照片式底图。必须记录它是生成素材，并保持照片层和装饰层分离；底图中不提前画入整套纸云串雨，否则无法独立控制装饰动作。

可用的构图描述：

> 一张真实日常摄影感的咖啡静物照片。略俯视的近距离视角，琥珀色旧木桌上放着两只灰紫粗陶咖啡杯和一只盛甜点的自然白瓷盘，局部午后阳光照亮木纹与食物，周围保留有细节的深灰暗面。物件自然错落，画面上方留出低干扰空间。颜色克制，材料真实，白盘不染黄。只生成照片，不加入装饰、文字、边框或应用界面。

这是一段创作描述，不是要求每张图都重复同一套咖啡物件。主题可以替换为窗边、旅行、植物或街角，但生活感、材料和留白原则保持一致。

生成或编辑操作只允许使用 `image_gen.imagegen`；不可用就停止该步骤，不切换其他图片服务。

## 参考截图的排除范围

- 手机状态栏、头像、点赞、评论、收藏和分享按钮。
- 标题、正文、翻译标签、字幕、播放图标和平台水印。
- 贴在照片上的英文说明或装饰性标题。
- 后续参考中的角色妆造、恐怖气氛、游戏菜单及与当前日常主题无关的文字。

照片里的实物印字可作为原照片内容保留，但不能据此自动生成新的招牌、品牌或文字排版。只需要风格时，无须裁出或复制参考截图中的照片。

## 摄影层的验收

静止时主体仍是照片；白色与肤色自然，主要物件没有被装饰遮住；暖色来自材料和光，不来自整张黄色遮罩。任何生成或编辑过的底图都应能与原始输入区分，并在交付说明中标明。
