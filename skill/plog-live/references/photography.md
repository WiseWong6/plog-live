# 图片处理

## 工具配置与来源

`prepare` 的图片工具默认随宿主环境判定：Codex 内默认 `--image-host codex`，工具为 `image_gen.imagegen`；其他环境默认按平台自带图片能力处理，先核对工具支持原图编辑，再显式加 `--image-host other --image-tool 实际工具名`。这项配置只决定图片编辑工具，苹果导出仍需主技能列出的运行环境。

调用材料由 `prepare` 写入 `image-tool-request.json` 和 `prompt.txt`。完成图片编辑后，将实际调用标识写入来源文件，供 `grade --provenance` 使用：

```json
{"tool":"image_gen.imagegen","toolCallId":"实际调用标识"}
```

其他环境使用：

```json
{"host":"other","tool":"实际工具名","toolCallId":"实际调用标识"}
```

工具名称必须与任务配置一致。Codex 内置工具失败时不切换第三方；其他环境没有可用的原图编辑能力时说明缺少的能力，不自动安装服务。

## 格式兼容

遇到格式不支持、方向异常或 `invalid_image_file` 等错误，自动转换后重试图片工具：

```sh
node scripts/normalize-input.mjs /任务目录 '实际格式错误原因'
```

程序保留原件，将八位 RGB 图片转为标准 PNG，修正显示方向，核对尺寸、颜色空间和解码像素，并更新工具请求路径。查看转换结果后继续原任务，无需让用户手动转图。

高动态范围、多帧或无法解码的输入，只有能完整保留内容和颜色时才转换；否则报告具体限制。原实况标识以归档原件为准。

## 盲测

同轮固定提示词，只替换英文短句；所有首次结果进入对比页。检查主体光影是否集中、暗部是否有层次、已有细节是否清楚，以及物件与四边取景是否保持。比例错误时重新处理，不裁边补救。
