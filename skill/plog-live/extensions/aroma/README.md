# 食物香气

两至五缕暖白半透明细雾，从热饮或热食表面缓慢卷起、散开、淡去。使用调色后的照片作为固定底图。

```sh
node extensions/aroma/create.mjs /调色后照片.png /香气布局.json /新场景目录
node scripts/render-scene.mjs --scene /新场景目录 --out /新导出目录
```

香气使用独立制作入口。需要实况配对时，将导出的封面和视频交给[苹果封装工具](../../native/README.md)。

观察食物表面或液面，把每缕 `origin` 放在散发区域内，用 `origins` 椭圆记录区域，再调整高度、侧移、摆幅和雾宽。允许细雾经过食物，局部避让英文。仅用于适合表现热气的画面，避开冷饮与冰凉甜点。

所有运动按固定时间计算，循环和回拖保持一致。原动态版需要物体跟随，暂不支持。
