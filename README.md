# PLOG · 日常奇遇

真实摄影质感的静态底图，加上一件超现实的小事，交付苹果实况照片所需资源。首版实现「咖啡上的纸片雨帘」：一朵深蓝纸片云，细线串着灰蓝、奶白、深蓝和少量砖红水滴，在杯子上方轻摆。

本项目遵守 [scenes 的目录与交付约定](../../README.md#这个文件夹的规矩) 和 [统一播放控件标准](../../README.md#统一播放控件标准)。开发与验收期间保留在「未完成」，使用独立 Git 仓库；不修改其他作品。

## 先看作品

- 双击 `examples/paper-rain/scene/index.html` 离线播放，无需服务器或联网。
- 导出文件位于 `delivery/paper-rain/`。普通视频仅用于预览，实况资源位于其中的 `live-photo/`。
- 底图是 Codex 内置图片工具生成的咖啡馆场景，不是用户的实拍记录。生成来源与完整提示词见 `examples/paper-rain/source-generation.md`。
- 页面只保留统一播放控件；控件不会出现在封面或视频里。

## 可复用技能

`skill/plog-live/` 是完整、可独立搬走的技能包，包含主流程、参考规范、场景模板、导出程序和苹果原生封装源码。手动选用 `plog-live` 后执行，不根据普通照片关键词自动启动。

本机技能入口为 `~/.agents/skills/plog-live`，通过软链接指向本项目中的技能包，只有一份源文件。新会话中手动选择 `$plog-live`；当前会话的技能列表不会因此自动刷新。以后迁移项目位置时同步更新这个入口。

本轮只有纸片雨帘正式实现；流星、亮片山水、泡泡、飞鸟、雪花、月亮和拼图已写入设计配方，尚不作为可运行效果交付。

## 换照片与制作

在本项目目录执行，所有输出目录必须是尚不存在的新目录，程序不会覆盖已有作品：

```sh
node skill/plog-live/scripts/create-scene.mjs --photo /绝对路径/照片.png --out /绝对路径/新场景 --config /绝对路径/配置.json
node skill/plog-live/scripts/render-scene.mjs --scene /绝对路径/新场景 --out /绝对路径/新导出目录
skill/plog-live/scripts/live-photo.sh pack --photo /绝对路径/新导出目录/cover.png --video /绝对路径/新导出目录/preview.mp4 --output /绝对路径/实况资源 --name paper-rain --key-time 1.5
```

配置文件可省略。示例配置在 `examples/paper-rain/config.json`；云位置、雨帘长度等使用 0–1 的相对照片坐标。首版输入为 PNG、JPEG、WebP，原图逐字节复制；默认读取原图比例，最长边不超过 1920 像素且不放大原图，尺寸取偶数。只有显式指定画布宽高时才按指定构图填满画布，可能裁掉边缘，原图不改写。本次样片显式使用 1440×1920。需要真正修改照片时仅调用宿主内置图片工具。

网页预览只需要现代浏览器。导出复用已安装的 Chrome、Node.js 和 FFmpeg；程序用自己的临时浏览器目录，通过管道逐帧送入视频编码器，不操作用户的浏览器、不启动 HTTP 服务、不留下逐帧图片。结束时关闭自己启动的进程并清理临时目录。Chrome 可通过 `--browser /可执行文件` 或 `PLOG_CHROME_PATH` 指定。

创建场景通过 macOS 自带的 `sips` 只读照片尺寸。苹果资源封装当前需要 macOS 26 或更高版本和 Apple 命令行开发工具 26 或更高版本；这是首版程序限制。编译入口不安装软件、不接受许可证、不改全局工具选择。原生工具说明见 `skill/plog-live/native/README.md`。

## 验收边界

二十张外部照片默认适配测试已完成：技术检查 20/20 通过，匿名封面构图评审 7/20 可接受。原图、动效和失败原因见 [离线对照页](delivery/blind-20-20260927/index.html)，方法、来源和逐张结果见 [测试报告](delivery/blind-20-20260927/report.md)。本轮保持技能版本不变，没有逐张调整参数；它验证默认适配能力，不代表人工定制后的质量。

导出报告记录循环、回拖一致性、运动存在、视频尺寸、帧数和音轨。苹果资源报告另行记录配对标识、封面时间及系统解码，不能把这些检查称为已通过 iPhone 验收。

本次样片已通过：1440×1920、3 秒、90 帧、无音轨；首尾完全一致、回拖一致；JPEG 与 MOV 标识相同、1.5 秒封面标记对齐实际帧；苹果系统返回完整实况照片对象。相册导入、iPhone 长按及平台发布尚未验收。检查报告与导入命令见 `delivery/paper-rain/README.md`。

人工验收：打开离线页面检查雨帘大小、纸片质感、摆动节奏与杯子的位置；拖动进度、暂停、重播并试一次倍速；把完整配对资源作为一张资产导入苹果「照片」，在 iPhone 上长按确认。发布平台的上传与播放另行验收。本轮不自动写入用户相册。
